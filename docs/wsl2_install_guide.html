How To Install WSL2 on Windows 10/11 Step-by-Step Guide

1. Introduction to WSL and WSL2

Learn how to install WSL2 on Windows 10/11 and run a Linux environment directly on Windows without needing a virtual machine.". It is especially useful for developers working in environments that require Linux tools and scripts. WSL1 runs Linux binaries directly on the Windows kernel, while WSL2 provides a more complete Linux kernel, allowing for better compatibility, performance, and more advanced features like Docker support.

2. System Requirements

  • Windows 10 Version: You need at least version 1903 (build 18362) or higher for WSL2.
  • Windows 11: Fully supported.
You can check your version by typing winver in the Start menu search or command prompt.

3. Check Windows Version

  1. Press Win + R to open the Run dialog box.
  2. Type winver and press Enter.
  3. Confirm that your version is 1903 or higher for Windows 10, or Windows 11.
  If your Windows version is older, you’ll need to update before proceeding.

4. Enable WSL and Virtual Machine Platform Features

WSL2 requires two optional features to be enabled: WSL and Virtual Machine Platform.
    1. Open PowerShell as Administrator by typing powershell into the Start menu, then right-clicking and selecting Run as Administrator.
    2. Run the following command to enable WSL:
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
    1. Next, enable the Virtual Machine Platform feature with this command:
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
  1. Restart your computer to apply the changes.

5. Install WSL2 Kernel Update

Once your system restarts, you'll need to download and install the Linux Kernel Update Package for WSL2. Follow these steps:
  1. Visit the official Microsoft WSL2 kernel update page: Download WSL2 Linux Kernel Update
  2. Download the update package and run the installer.

6. Set WSL2 as the Default Version

To set WSL2 as the default version, open PowerShell as Administrator again and run: 
wsl --set-default-version 2
This ensures that any new Linux distributions you install will default to WSL2.

7. Install a Linux Distribution

You can now install your preferred Linux distribution from the Microsoft Store.
  1. Open the Microsoft Store.
  2. Search for a distribution (e.g., Ubuntu, Debian, Kali Linux).
  3. Select the distribution and click Install.
  4. Once installed, launch the Linux distribution. You'll be asked to set up a username and password.
  Example: Installing Ubuntu:
  • Search for "Ubuntu" in the Microsoft Store.
  • Click on Install.
  • Once installation is done, launch it from the Start menu.

8. Updating from WSL1 to WSL2

If you've already been using WSL1 and want to upgrade to WSL2, follow these steps:
    1. List installed distributions to check if they're running WSL1 or WSL2:
wsl --list --verbose
    1. Set a specific distribution to use WSL2 by running:
wsl --set-version <distro_name> 2
Replace <distro_name> with the name of your installed Linux distro (e.g., Ubuntu). Example: 
wsl --set-version Ubuntu 2

9. Updating Linux Distribution

Once your Linux distro is set up, it's important to update the package manager and the installed packages.
    1. Open your Linux terminal (Ubuntu, for example).
    2. Run the following commands to update and upgrade packages:
sudo apt update
sudo apt upgrade

10. Accessing WSL Files from Windows

  To access your WSL files from Windows File Explorer:
  1. Open File Explorer.
  2. In the address bar, type: 
    \\wsl$
  3. You’ll see your running Linux distributions. You can access their files directly from here.

11. Accessing Windows Files from WSL

You can access your Windows files directly from WSL by navigating to the /mnt directory. For example:

  • C: drive: /mnt/c/
  • D: drive: /mnt/d/
Example: 
cd /mnt/c/Users/YourUsername/Documents

12. Configuring WSL (Optional)

To configure memory, processors, or other system settings, create a .wslconfig file in your user directory (C:\Users\<YourUsername>\). Here’s an example of a configuration file: 
[wsl2]
# Settings apply across all Linux distros running on WSL 2
# Can see memory in wsl2 with "free -m"
# Goes in windows home directory as .wslconfig
[wsl2]

# Limits VM memory to use no more than 48 GB, defaults to 50% of ram
memory=24GB

# Sets the VM to use 32 virtual processors
processors=32

# Sets the amount of swap storage space to 64GB, default is 25% of available RAM
swap=64GB

13. Basic Troubleshooting

  • Kernel update errors: If you encounter errors related to the kernel, ensure that you’ve downloaded and installed the latest kernel package.
  • Virtual Machine not starting: Ensure that the Virtual Machine Platform feature is enabled.
  • Performance issues: Configure your .wslconfig file to optimize resource usage.

14. Useful Commands

  • List installed distributions: 
    wsl --list --verbose
  • Set default WSL version: 
    wsl --set-default-version 2
  • Change version of a specific distribution: 
    wsl --set-version <distro_name> 2
  • Terminate a running distribution: 
    wsl --terminate <distro_name>
  • Unregister a distribution (this deletes the distro): 
    wsl --unregister <distro_name>
  • Launch a specific distribution: 
    wsl -d <distro_name>

15. Conclusion

WSL2 is a powerful tool that provides a full Linux environment on Windows without the need for a virtual machine. By following this guide, you’ve enabled WSL2, installed a Linux distribution, and learned useful commands for managing your environment.
